Steam

Store/app info works with no setup. To let the agent check your owned games and playtime, add a free API key from steamcommunity.com/dev/apikey plus your numeric SteamID64.

Personal Instructions

Tell your companion anything it should always know or do — tone, how to address you, things to avoid, etc. This is added to every conversation.

Memory

Facts your companion has saved about you. It can add or remove these itself during conversation, or you can manage them directly here. Facts tagged to a game only get shown to the companion while that game is active; general facts always show.

Game State

What the companion has picked up automatically from on-screen text via background OCR, refreshed periodically while a game is focused. This is separate from Memory — only facts the companion explicitly decides are worth remembering long-term get saved there.
